# BTC Trader Pro – Lizenzen & Preise

BTC Trader Pro kann im **TEST-Modus kostenlos und zeitlich unbegrenzt** ausprobiert werden. Für den Echtgeldhandel im **LIVE-Modus** ist eine gültige Lizenz erforderlich.

## LIVE-Lizenzen

| Laufzeit | Preis |
| --- | ---: |
| 1 Woche | **2 USDC** |
| 1 Monat | **5 USDC** |
| 1 Jahr | **10 USDC** |
| Lifetime | **50 USDC** |

Die Lizenz wird innerhalb von BTC Trader Pro ausgewählt und mit **USDC im Base-Netzwerk** bezahlt. Zusätzliche Netzwerkgebühren können anfallen.

Nach Erkennung einer gültigen Zahlung wird die Lizenz automatisch aktiviert. Für eine Verlängerung ist eine **neue Zahlung** erforderlich; es findet keine automatische Abbuchung statt.

**Hinweis:** Diese Übersicht zeigt die Lizenzoptionen von BTC Trader Pro R0020. Vor einer Zahlung bitte die aktuell in der Software angezeigte Laufzeit und den Betrag prüfen.
